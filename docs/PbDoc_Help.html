概述

PbDoc 是一个纯 PureBasic 实现的 Word 文档操作库，无需安装 Microsoft Office 或任何第三方依赖，即可创建符合 Office Open XML 标准的 .docx 文件。

该库参考 Python 的 python-docx 项目编写，使用 PureBasic 内置的 Packer（ZIP压缩）库实现。

注意：使用 PbDoc 库前，需要在代码开头添加 XIncludeFile "PbDoc.pb" 以引入库文件，并调用 PbDoc_Init() 进行初始化。

主要功能

  • 创建 Word .docx 文件
  • 文档属性设置（标题、作者、主题、公司）
  • 段落操作（添加、对齐、样式）
  • 1-9级标题
  • 字体格式（粗体、斜体、下划线、删除线、上下标、字体名、颜色、高亮、字号）
  • 段落格式（缩进、间距、行距、分页控制）
  • Tab制表符（左/右/居中/小数点对齐，5种前导符）
  • 表格操作（创建、样式、对齐、列宽、单元格）
  • 超链接
  • 分页符、换行符、分栏符
  • 页面设置（纸张大小、边距、方向）
  • 单位转换（EMU/缇/磅/厘米/英寸）

初始化与清理

PbDoc_Init()
初始化 PbDoc 库。在使用任何 PbDoc 功能之前必须调用此函数。
返回值： 成功返回 #True，失败返回 #False。
; 初始化 PbDoc 库 If PbDoc_Init() = #False Debug "初始化失败" End EndIf
PbDoc_Cleanup()
清理 PbDoc 库占用的所有资源。在程序结束前应调用此函数。

文档操作

PbDocument_Create()
创建一个新的空白文档。返回文档对象指针，后续所有操作都基于此指针。
返回值： 文档对象指针 (PbDocument)。失败返回 0。
*doc.PbDocument = PbDocument_Create() If *doc = 0 Debug "创建文档失败" EndIf
PbDocument_Save(*doc.PbDocument, filePath.s)
将文档保存为 .docx 文件。该函数会生成符合 Office Open XML 标准的 ZIP 压缩包。
参数类型说明
*docPbDocument文档对象指针
filePathString输出文件路径（.docx 后缀）
返回值： 成功返回 #True，失败返回 #False。
If PbDocument_Save(*doc, "output.docx") Debug "保存成功" Else Debug "保存失败: " + PbDoc_GetLastError() EndIf
PbDocument_Free(*doc.PbDocument)
释放文档占用的所有内存资源。保存后应调用此函数。
PbDocument_SetTitle(*doc.PbDocument, title.s)
设置文档标题。此属性会写入 docProps/core.xml。
参数类型说明
*docPbDocument文档对象指针
titleString文档标题
PbDocument_SetAuthor(*doc.PbDocument, author.s)
设置文档作者。
PbDocument_SetSubject(*doc.PbDocument, subject.s)
设置文档主题。
PbDocument_SetCompany(*doc.PbDocument, company.s)
设置公司名称。此属性会写入 docProps/app.xml。

段落操作

PbDoc_Document_AddParagraph(*doc.PbDocument, text.s)
添加段落。如果提供文本，会自动创建一个包含该文本的 Run。
参数类型说明
*docPbDocument文档对象指针
textString段落文本（可为空字符串）
返回值： 段落对象指针 (PbDocParagraph)。
; 添加普通段落 PbDoc_Document_AddParagraph(*doc, "这是段落文本") ; 添加空段落，后续手动添加Run *para = PbDoc_Document_AddParagraph(*doc, "")
PbDoc_Paragraph_SetAlignment(*para.PbDocParagraph, alignment.l)
设置段落对齐方式。
参数类型说明
alignmentInteger对齐方式枚举：#PbDoc_ALIGN_LEFT, #PbDoc_ALIGN_CENTER, #PbDoc_ALIGN_RIGHT, #PbDoc_ALIGN_JUSTIFY, #PbDoc_ALIGN_DISTRIBUTE
*para = PbDoc_Document_AddParagraph(*doc, "居中文字") PbDoc_Paragraph_SetAlignment(*para, #PbDoc_ALIGN_CENTER)
PbDoc_Document_AddHeading(*doc.PbDocument, text.s, level.l)
添加标题段落。标题会自动应用内置的 Heading 样式。
参数类型说明
textString标题文本
levelInteger标题级别（1-9），1为最高级
返回值： 段落对象指针。
PbDoc_Document_AddHeading(*doc, "第一章 引言", 1) PbDoc_Document_AddHeading(*doc, "1.1 背景", 2)

Run 操作

Run 是段落中具有相同格式的一段文本。一个段落可以包含多个 Run，每个 Run 可以有不同的格式。

PbDoc_Paragraph_AddRun(*para.PbDocParagraph, text.s)
向段落添加一个文本运行 (Run)。
返回值： Run 对象指针 (PbDocRun)。
*para = PbDoc_Document_AddParagraph(*doc, "") *run1 = PbDoc_Paragraph_AddRun(*para, "普通文字 ") *run2 = PbDoc_Paragraph_AddRun(*para, "粗体文字") PbDoc_Font_SetBold(*run2, #True)
PbDoc_Run_AddTab(*run.PbDocRun)
在 Run 中添加 Tab 制表符。
PbDoc_Run_AddBreak(*run.PbDocRun, breakType.l)
在 Run 中添加断行符。
参数类型说明
breakTypeInteger#PbDoc_BREAK_LINE（换行）、#PbDoc_BREAK_PAGE（分页）、#PbDoc_BREAK_COLUMN（分栏）

段落格式

PbDoc_ParaFormat_SetFirstLineIndent(*para.PbDocParagraph, emu.q)
设置首行缩进。参数为 EMU 单位。
; 首行缩进2字符（约0.74厘米） PbDoc_ParaFormat_SetFirstLineIndent(*para, PbDoc_CmToEmu(0.74))
PbDoc_ParaFormat_SetLeftIndent(*para.PbDocParagraph, emu.q)
设置左缩进。
PbDoc_ParaFormat_SetRightIndent(*para.PbDocParagraph, emu.q)
设置右缩进。
PbDoc_ParaFormat_SetHangingIndent(*para.PbDocParagraph, emu.q)
设置悬挂缩进。
PbDoc_ParaFormat_SetSpaceBefore(*para.PbDocParagraph, emu.q)
设置段前间距。
; 段前间距12磅 PbDoc_ParaFormat_SetSpaceBefore(*para, PbDoc_PtToEmu(12))
PbDoc_ParaFormat_SetSpaceAfter(*para.PbDocParagraph, emu.q)
设置段后间距。
PbDoc_ParaFormat_SetLineSpacing(*para.PbDocParagraph, spacing.q, rule.l)
设置行间距。
参数类型说明
spacingQuad行间距值。自动行距: 240=1倍, 360=1.5倍, 480=2倍；精确/最小行距: 缇值

; 1.5倍行距 PbDoc_ParaFormat_SetLineSpacing(*para, 360, #PbDoc_LINE_SPACING_AUTO) ; 固定20磅行距 PbDoc_ParaFormat_SetLineSpacing(*para, PbDoc_PtToTwips(20), #PbDoc_LINE_SPACING_EXACT)
PbDoc_ParaFormat_SetKeepNext(*para.PbDocParagraph, keepNext.l)
设置与下段同页，防止段落与下一段之间出现分页符。
PbDoc_ParaFormat_SetKeepLines(*para.PbDocParagraph, keepLines.l)
设置段中不分页。
PbDoc_ParaFormat_SetWidowControl(*para.PbDocParagraph, widowControl.l)
设置孤行控制，防止段落首行或末行单独出现在页面顶部或底部。
PbDoc_ParaFormat_AddTabStop(*para.PbDocParagraph, position.q, alignment.l, leader.l)
添加制表符停止位。
参数类型说明
positionQuad位置（EMU单位）
alignmentInteger对齐方式：#PbDoc_TAB_LEFT, #PbDoc_TAB_CENTER, #PbDoc_TAB_RIGHT, #PbDoc_TAB_DECIMAL
leaderInteger前导符：#PbDoc_TAB_LEADER_NONE, #PbDoc_TAB_LEADER_DOTS, #PbDoc_TAB_LEADER_DASHES, #PbDoc_TAB_LEADER_LINES
; 右对齐Tab，带点线前导符（目录样式） PbDoc_ParaFormat_AddTabStop(*para, PbDoc_CmToEmu(14), #PbDoc_TAB_RIGHT, #PbDoc_TAB_LEADER_DOTS) *run1 = PbDoc_Paragraph_AddRun(*para, "第一章 引言") PbDoc_Run_AddTab(*run1) *run2 = PbDoc_Paragraph_AddRun(*para, "1")

单位转换

PbDoc 使用两种内部单位：EMU（English Metric Units）和缇（Twips）。EMU 用于段落格式参数，缇用于页面设置参数。

PbDoc_InchesToEmu(inches.d) / PbDoc_CmToEmu(cm.d) / PbDoc_PtToEmu(pt.d)
英寸/厘米/磅 转 EMU。用于段落格式参数。
PbDoc_CmToTwips(cm.d) / PbDoc_InchesToTwips(inches.d) / PbDoc_PtToTwips(pt.d)
厘米/英寸/磅 转 缇。用于页面设置参数。
常用换算：
1 英寸 = 914400 EMU = 1440 缇
1 厘米 = 360000 EMU = 567 缇
1 磅 = 12700 EMU = 20 缇

示例代码

示例1：创建基本Word文档

; PbDoc - 创建基本Word文档示例 XIncludeFile "../PbDoc.pb" PbDoc_Init() *doc.PbDocument = PbDocument_Create() ; 设置文档属性 PbDocument_SetTitle(*doc, "我的文档") PbDocument_SetAuthor(*doc, "PbDoc 用户") ; 添加标题和段落 PbDoc_Document_AddHeading(*doc, "第一章 引言", 1) PbDoc_Document_AddParagraph(*doc, "这是文档的第一段内容。") ; 保存文件 PbDocument_Save(*doc, "output.docx") PbDocument_Free(*doc) PbDoc_Cleanup()

示例2：带格式的文本

; 添加多Run段落（不同格式） *para = PbDoc_Document_AddParagraph(*doc, "") *run1 = PbDoc_Paragraph_AddRun(*para, "粗体文字 ") PbDoc_Font_SetBold(*run1, #True) *run2 = PbDoc_Paragraph_AddRun(*para, "红色文字 ") PbDoc_Font_SetColorHex(*run2, "FF0000") *run3 = PbDoc_Paragraph_AddRun(*para, "18pt文字") PbDoc_Font_SetSize(*run3, 18)

示例3：创建表格

; 创建3行4列表格 *table = PbDoc_Document_AddTable(*doc, 3, 4) PbDoc_Table_SetStyle(*table, "TableGrid") ; 填充表头 PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 0), "姓名") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 1), "年龄") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 2), "城市") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 3), "职业") ; 填充数据 PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 0), "张三") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 1), "28") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 2), "北京") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 3), "工程师")
