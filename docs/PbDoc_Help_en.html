Overview

PbDoc is a Word document processing library implemented entirely in PureBasic. It can create .docx files conforming to the Office Open XML standard without requiring Microsoft Office or any third-party dependencies.

This library is written with reference to the Python python-docx project, using PureBasic's built-in Packer (ZIP compression) library.

Note: Before using the PbDoc library, you need to add XIncludeFile "PbDoc.pb" at the beginning of your code to include the library file, and call PbDoc_Init() for initialization.

Key Features

  • Create Word .docx files
  • Document property settings (title, author, subject, company)
  • Paragraph operations (add, align, style)
  • Heading levels 1-9
  • Font formatting (bold, italic, underline, strikethrough, superscript/subscript, font name, color, highlight, font size)
  • Paragraph formatting (indentation, spacing, line spacing, page break control)
  • Tab stops (left/right/center/decimal alignment, 5 leader types)
  • Table operations (create, style, alignment, column width, cells)
  • Hyperlinks
  • Page breaks, line breaks, column breaks
  • Page setup (paper size, margins, orientation)
  • Unit conversion (EMU/twips/points/cm/inches)

Initialization and Cleanup

PbDoc_Init()
Initialize the PbDoc library. This function must be called before using any PbDoc features.
Returns: #True on success, #False on failure.
; Initialize PbDoc library If PbDoc_Init() = #False Debug "Initialization failed" End EndIf
PbDoc_Cleanup()
Clean up all resources used by the PbDoc library. This function should be called before the program exits.

Document Operations

PbDocument_Create()
Create a new blank document. Returns a document object pointer, which is used for all subsequent operations.
Returns: Document object pointer (PbDocument). Returns 0 on failure.
*doc.PbDocument = PbDocument_Create() If *doc = 0 Debug "Failed to create document" EndIf
PbDocument_Save(*doc.PbDocument, filePath.s)
Save the document as a .docx file. This function generates a ZIP archive conforming to the Office Open XML standard.
ParameterTypeDescription
*docPbDocumentDocument object pointer
filePathStringOutput file path (.docx extension)
Returns: #True on success, #False on failure.
If PbDocument_Save(*doc, "output.docx") Debug "Save successful" Else Debug "Save failed: " + PbDoc_GetLastError() EndIf
PbDocument_Free(*doc.PbDocument)
Release all memory resources used by the document. This should be called after saving.
PbDocument_SetTitle(*doc.PbDocument, title.s)
Set the document title. This property is written to docProps/core.xml.
ParameterTypeDescription
*docPbDocumentDocument object pointer
titleStringDocument title
PbDocument_SetAuthor(*doc.PbDocument, author.s)
Set the document author.
PbDocument_SetSubject(*doc.PbDocument, subject.s)
Set the document subject.
PbDocument_SetCompany(*doc.PbDocument, company.s)
Set the company name. This property is written to docProps/app.xml.

Paragraph Operations

PbDoc_Document_AddParagraph(*doc.PbDocument, text.s)
Add a paragraph. If text is provided, a Run containing that text is automatically created.
ParameterTypeDescription
*docPbDocumentDocument object pointer
textStringParagraph text (can be an empty string)
Returns: Paragraph object pointer (PbDocParagraph).
; Add a normal paragraph PbDoc_Document_AddParagraph(*doc, "This is paragraph text") ; Add an empty paragraph, then manually add Runs *para = PbDoc_Document_AddParagraph(*doc, "")
PbDoc_Paragraph_SetAlignment(*para.PbDocParagraph, alignment.l)
Set paragraph alignment.
ParameterTypeDescription
alignmentIntegerAlignment enum: #PbDoc_ALIGN_LEFT, #PbDoc_ALIGN_CENTER, #PbDoc_ALIGN_RIGHT, #PbDoc_ALIGN_JUSTIFY, #PbDoc_ALIGN_DISTRIBUTE
*para = PbDoc_Document_AddParagraph(*doc, "Centered text") PbDoc_Paragraph_SetAlignment(*para, #PbDoc_ALIGN_CENTER)
PbDoc_Document_AddHeading(*doc.PbDocument, text.s, level.l)
Add a heading paragraph. Headings automatically apply built-in Heading styles.
ParameterTypeDescription
textStringHeading text
levelIntegerHeading level (1-9), 1 is the highest level
Returns: Paragraph object pointer.
PbDoc_Document_AddHeading(*doc, "Chapter 1 Introduction", 1) PbDoc_Document_AddHeading(*doc, "1.1 Background", 2)

Run Operations

A Run is a segment of text within a paragraph that has the same formatting. A paragraph can contain multiple Runs, each with different formatting.

PbDoc_Paragraph_AddRun(*para.PbDocParagraph, text.s)
Add a text run (Run) to a paragraph.
Returns: Run object pointer (PbDocRun).
*para = PbDoc_Document_AddParagraph(*doc, "") *run1 = PbDoc_Paragraph_AddRun(*para, "Normal text ") *run2 = PbDoc_Paragraph_AddRun(*para, "Bold text") PbDoc_Font_SetBold(*run2, #True)
PbDoc_Run_AddTab(*run.PbDocRun)
Add a Tab character to a Run.
PbDoc_Run_AddBreak(*run.PbDocRun, breakType.l)
Add a break to a Run.
ParameterTypeDescription
breakTypeInteger#PbDoc_BREAK_LINE (line break), #PbDoc_BREAK_PAGE (page break), #PbDoc_BREAK_COLUMN (column break)

Unit Conversion

PbDoc uses two internal units: EMU (English Metric Units) and twips. EMU is used for paragraph formatting parameters, and twips are used for page setup parameters.

PbDoc_InchesToEmu(inches.d) / PbDoc_CmToEmu(cm.d) / PbDoc_PtToEmu(pt.d)
Convert inches/centimeters/points to EMU. Used for paragraph formatting parameters.
PbDoc_CmToTwips(cm.d) / PbDoc_InchesToTwips(inches.d) / PbDoc_PtToTwips(pt.d)
Convert centimeters/inches/points to twips. Used for page setup parameters.
Common conversions:
1 inch = 914400 EMU = 1440 twips
1 cm = 360000 EMU = 567 twips
1 point = 12700 EMU = 20 twips

Example Code

Example 1: Create a Basic Word Document

; PbDoc - Create a basic Word document example XIncludeFile "../PbDoc.pb" PbDoc_Init() *doc.PbDocument = PbDocument_Create() ; Set document properties PbDocument_SetTitle(*doc, "My Document") PbDocument_SetAuthor(*doc, "PbDoc User") ; Add heading and paragraph PbDoc_Document_AddHeading(*doc, "Chapter 1 Introduction", 1) PbDoc_Document_AddParagraph(*doc, "This is the first paragraph.") ; Save the file PbDocument_Save(*doc, "output.docx") PbDocument_Free(*doc) PbDoc_Cleanup()

Example 2: Formatted Text

; Add a multi-Run paragraph (different formatting) *para = PbDoc_Document_AddParagraph(*doc, "") *run1 = PbDoc_Paragraph_AddRun(*para, "Bold text ") PbDoc_Font_SetBold(*run1, #True) *run2 = PbDoc_Paragraph_AddRun(*para, "Red text ") PbDoc_Font_SetColorHex(*run2, "FF0000") *run3 = PbDoc_Paragraph_AddRun(*para, "18pt text") PbDoc_Font_SetSize(*run3, 18)

Example 3: Create a Table

; Create a 3-row, 4-column table *table = PbDoc_Document_AddTable(*doc, 3, 4) PbDoc_Table_SetStyle(*table, "TableGrid") ; Fill header row PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 0), "Name") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 1), "Age") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 2), "City") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 0, 3), "Occupation") ; Fill data row PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 0), "Zhang San") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 1), "28") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 2), "Beijing") PbDoc_Cell_SetText(PbDoc_Table_GetCell(*table, 1, 3), "Engineer")
